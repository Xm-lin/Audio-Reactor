# 🎵 Audio Reactor

A lightweight, standalone Python-based audio visualization tool featuring a system tray interface and a clean, console-less window.

---

## ✨ Features

- **Real-time Audio Visualization**: Dynamically reacts to system audio.
- **No Console Window**: Runs quietly in the background without the annoying command prompt black box.
- **System Tray Integration**: Easily manage the app from the taskbar using `pystray`.
- **Standalone Executable**: Download and run instantly without needing a local Python environment.

---

## 📦 How to Download & Use

If you just want to use the application without modifying the source code:
1. Head over to the **[Releases](../../releases)** section on the right sidebar.
2. Download the latest **`AUDIO_REACTOR.exe`** binary.
3. Double-click to run!
